Feature matrix · method and honest state

Every cell still reads not_checked — and that is the correct thing to publish

Method

  1. Freeze the rows first. Five rows, because five checks already exist and each has a mutation proving it can go red: read_path_coverage (3), declared_total_parity (3), field_completeness (2), public_url (2), round_trip (1). Weights in one line, FEATURE_WEIGHTS.
  2. One worker per column (board), never per row — the expensive part is fetching the board, not judging the feature.
  3. Cells carry evidence, not prose: path, quote, fetched_at.
  4. Merge with a script. tools/cells_from_pytest.py folds a pytest report into cell JSONL; the store is append-only, so merging is >>.
  5. Verify by re-deriving from evidence alone; for the five pytest rows the stronger form already exists — pytest -m mutation.
  6. Score last, as a computed column, so re-weighting costs zero crawls.

Where it actually stands

  • 5 rows × the 220 boards the coverage table counted on 2026-09-10 = 1,100 cells, 0 written: wc -l data/feature_cells.jsonl → 0 on 2026-09-11. The denominator is left at that read on purpose — GET /api/coverage answers 401 without an owner session, and this deck does not log into the box to freshen a number.
  • Why: pytest-json-report is not installed and no new dependency was allowed, so no report exists to fold; and the completeness suite is network-marked, so no live crawl was run to produce one. Nothing was invented to fill the column.
  • A budget or cap stop is recorded as {"verdict":"not_checked","stop":"truncated"} with the gate message as evidence — never as a filled cell and never as absent.
  • The fold can never emit partial: a pytest assertion is binary. partial can only come from a human or a swarm worker; app/coverage.py already scores it at 0.5.
  • Six candidate rows from the brief (pagination_followed, detail_fetch, feed_available, robots_blocked, method_justification, completeness_verdict) are deliberately not in the vocabulary: nothing produces them yet, so they would add a column of not_checked with no path to filling it.
