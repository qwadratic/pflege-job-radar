## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
Замер на живых данных 2026-09-22, 2576 открытых вакансий.

ПРОБЛЕМА ПОДТВЕРЖДЕНА. app/data.py _q_match ищет в title, employer, city, department_raw, clinic_name -- тела там нет. Более того, description вообще не входит в JOB_COLS (app/data.py:19), то есть API его не загружает и поиск физически не может в него заглянуть. classify.department_hint(title) тоже принимает только заголовок (плюс у части адаптеров короткий dept/untertitel).

Масштаб: 1098 из 2576 открытых вакансий (43%) содержат специальность только в теле. По примерам из отчёта: Stroke Unit -- 23 в заголовке против 91 в теле, Dialyse -- 23 против 86. Хуже всего Intensiv (596 только в теле), Anästhesie (415), Psychiatrie (277), Notaufnahme (206).

НО НАИВНОЕ РЕШЕНИЕ ХУЖЕ ПРОБЛЕМЫ. Выборка контекстов показала, что большинство вхождений в теле -- не специальность вакансии:
- контакты отделений: 'Neurologie & Stroke Unit Sekretariat 08141/99-6103'
- описание больницы: 'verfügt über ... eine Chest Pain Unit, eine Stroke Unit, eine Akutgeriatrie'
- меню сайта, попавшее в текст: 'Neurologie & Stroke Unit Physiotherapie Radiologie Zentrale Notaufnahme'
- перечень всех отделений в инициативной заявке
Из шести проверенных вхождений Stroke Unit только два относились к самой вакансии. Если классифицировать по всему телу, человек выберет фасет 'Stroke Unit' и получит вакансии, где эта фраза стоит в телефонном справочнике.

ЧТО ИЗМЕРЕНО ПО ВАРИАНТАМ (title -> +enr_requirements -> +всё тело):
  Stroke     23 -> 24  -> 94
  Dialyse    23 -> 24  -> 94
  Intensiv  185 -> 282 -> 717
  Onkologie  46 -> 67  -> 236
  Palliativ  29 -> 49  -> 133
enr_requirements (секция 'Ihr Profil', заполнена у 1524 из 2576) даёт умеренный и чистый прирост -- для Intensiv +52%. Для Stroke/Dialyse почти не помогает, потому что отделение называют не в требованиях, а в описании задач и места работы.

department_raw как альтернатива не работает: заполнен только у 485 из 2576 (19%), и чаще всего это общее 'Pflegedienst' (71 строка). Для Stroke даёт +1 к заголовку.

ОТДЕЛЬНЫЙ ДЕФЕКТ, найден попутно: classify.department_hint возвращает next((n for n, r in _DEPT if r.search(s)), None) -- ПЕРВОЕ совпадение и только одно. Вакансия на интенсивную терапию с анестезией получает одну метку из двух. Фасет специальности поэтому неполон даже для заголовков.

BUT the review surfaced a SEPARATE, PRE-EXISTING regex-precision defect in patterns.json's department list, now far more consequential because department_hint scans hundreds of characters of Aufgaben/Profil text instead of a short title:
